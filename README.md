# Password-Manager

A personal password manager project built to learn basic cybersecurity concepts; such as encryption, hashing, and authentication.

Please note that this project is for personal and educational purposes, it is not intended for production use.

---

This password manager is a beginner-level cybersecurity project that is planned to store and manage passwords securely.
The goal for this project is to learn:

- Encryption and Decryption
- Password Hashing
- Secure Authentication
- File Storage
- Backend / Frontend Communication
